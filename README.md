# AITU Career Match

Веб-платформа подбора стажировок и начальных IT-позиций для студентов Astana IT University. Студент заполняет профиль (направление, навыки, предпочтения) и получает список вакансий, отсортированный по соответствию, с объяснением, почему вакансия подходит и каких навыков не хватает. Работодатели публикуют вакансии и обрабатывают отклики.

Проект создан по техническому заданию «AITU Career Match v1.0» (первая рабочая версия). Название и оформление не являются официальным сервисом университета. Язык интерфейса: английский.

## Статус проекта

Проект разрабатывается поэтапно. Этот раздел показывает, что готово на сегодня.

**Реализовано**

- Роли: студент и работодатель; регистрация, вход и выход; пароли хранятся как PBKDF2-хеши; повторный email отклоняется; обязательное согласие с правилами обработки данных; заблокированный аккаунт войти не может.
- Студент: профиль (направление, формат работы, город, навыки из общего справочника), каталог вакансий с поиском и фильтром по направлению, страница вакансии, персональные рекомендации, избранное, внутренний отклик на вакансию (один активный отклик на вакансию, повторный клик дубликат не создаёт), список откликов, отзыв заявки.
- Работодатель: регистрация компании, профиль компании, создание и редактирование вакансий (черновик), отправка вакансии на проверку, закрытие вакансии, просмотр откликов только на свои вакансии, смена статуса заявки с записью истории.
- Вакансии: статусы draft, pending, published, rejected, closed, expired; публикация возможна только при наличии хотя бы одного обязательного навыка и проверенной компании; изменение опубликованной вакансии отправляет её на повторную проверку; вакансии с истёкшим сроком автоматически получают статус expired и исключаются из каталога и рекомендаций.
- Подбор по формуле из ТЗ с объяснениями и блоком «What to learn» (см. ниже).
- 18 демонстрационных вакансий с пометкой Demo по 7 направлениям.
- База данных рассчитана на все сущности ТЗ (пользователи, профили, проекты, навыки и синонимы, вакансии, избранное, отклики, история статусов, журнал модерации).

**В разработке или не реализовано**

- Панель администратора: проверка компаний, модерация вакансий с причиной отклонения, блокировка, справочники, импорт CSV, журнал действий. Пока администратора нет, поэтому публикация вакансий работодателем недоступна (компания не может быть проверена).
- Аналитика рынка труда.
- Подтверждение email по ссылке, восстановление пароля, ограничение частоты попыток входа.
- Расширенный профиль студента (специальность, курс, год выпуска, проекты с навыками, опыт, языки, GitHub, портфолио, резюме в PDF): поля в базе есть, форм пока нет.
- Синонимы навыков в подборе, расширенные фильтры каталога и пагинация, удаление аккаунта.
- Docker Compose, PostgreSQL как основная база, ежедневное резервное копирование, тесты, пилотная оценка качества подбора (Precision@5), русская и казахская версии интерфейса.

## Алгоритм подбора

Оценка: `Score = 100 × (0.60·E + 0.15·D + 0.15·A + 0.05·F + 0.05·L)`

| Компонент | Значение |
|---|---|
| E | доля совпавших обязательных навыков |
| D | доля совпавших желательных навыков |
| A | совпадение направления (1 или 0) |
| F | совпадение формата работы (1 или 0) |
| L | совпадение местоположения (1 или 0); удалённая вакансия подходит по местоположению |

Если компонент неприменим (у вакансии нет желательных навыков или студент не указал формат или город), он исключается, а оставшиеся веса нормализуются до суммы 1. Учитываются только опубликованные активные вакансии. При равной оценке выше более новая вакансия. Одинаковые входные данные всегда дают одинаковый результат. Недостающий обязательный навык снижает оценку, но не блокирует отклик. Веса заданы в начале файла `recommender.py`.

Контрольный пример: навыки Python, SQL, Excel; направление Data Analytics; формат Hybrid; город Astana. Для вакансии «Data Analyst Intern» (обязательные Python, SQL, Excel, Power BI; желательный Tableau; Astana, Hybrid): E = 0.75, D = 0, A = F = L = 1, итог = 100 × (0.45 + 0 + 0.15 + 0.05 + 0.05) = **70.0**.

Оценка соответствия не является вероятностью найма.

## Технологии

Python 3.10+, FastAPI, SQLAlchemy, SQLite, Jinja2, Bootstrap 5.

## Установка и запуск

Нужны Python 3.10 или новее и Git.

```
git clone https://github.com/aluasarsenova25-coder/AITU-Career-Match.git
cd AITU-Career-Match
pip install -r requirements.txt
python seed.py
python -m uvicorn main:app --reload
```

После запуска сайт доступен по адресу http://127.0.0.1:8000.

- `python seed.py` создаёт файл базы данных `career_match.db`, справочник направлений и демонстрационные вакансии. Повторный запуск ничего не дублирует.
- Если нужна чистая база, остановите сервер, удалите файл `career_match.db` и снова выполните `python seed.py`.
- После изменения структуры базы в коде файл `career_match.db` нужно удалить и создать заново.

**Переменные окружения (необязательные)**

| Переменная | Назначение |
|---|---|
| `SECRET_KEY` | ключ подписи сессий; для публичного запуска обязательно заменить значение по умолчанию |
| `DATABASE_URL` | адрес базы данных; по умолчанию SQLite-файл `career_match.db` (подключение PostgreSQL заложено, но не проверялось) |

## Как проверить работу

**Студент**
1. Нажмите Sign up и создайте аккаунт.
2. В профиле выберите направление, формат, город и навыки, сохраните.
3. Откройте Recommendations: вакансии отсортированы по оценке, у каждой есть объяснение и подсветка навыков; справа блок «What to learn».
4. Откройте вакансию, сохраните её в избранное, откликнитесь (повторный отклик не создаётся), затем отзовите заявку в разделе Applications.

**Работодатель**
1. Нажмите For employers и зарегистрируйте компанию.
2. Создайте вакансию (+ New vacancy), выберите навыки; вакансия сохранится как черновик.
3. Отправка на проверку станет возможной после появления панели администратора (компания должна быть проверена).

| Файл | Назначение |

| `main.py` | маршруты студента и общие маршруты: каталог, вход, профиль, рекомендации, избранное, отклики |

| `requirements.txt` | список зависимостей |

## Приватность и ограничения

- Работодатель видит данные студента только после его отклика на вакансию этого работодателя.
- Чувствительные характеристики студента в подборе не используются.
- Демонстрационные вакансии не являются реальными предложениями; отклики на них сохраняются только в демо-базе и не передаются работодателям.
- Платформа оценивает соответствие указанным требованиям и не гарантирует приглашение или трудоустройство. Качество подбора зависит от полноты профиля и описания вакансии.
- Перед публичным запуском нужно определить ответственного за обработку данных, текст согласия и сроки хранения.
