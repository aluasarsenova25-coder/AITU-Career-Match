# AITU Career Match

Веб-платформа подбора стажировок и начальных IT-позиций для студентов Astana IT University. Студент заполняет профиль (направление, навыки, предпочтения) и получает упорядоченный список вакансий с объяснением, почему они подходят и каких навыков не хватает.

Проект создан по техническому заданию «AITU Career Match v1.0». Это первая рабочая версия (MVP). Название и оформление не являются официальным сервисом университета.

## Что реализовано

- Регистрация и вход по email и паролю (пароли хранятся как PBKDF2-хеши, повторный email отклоняется, обязательное согласие с правилами обработки данных).
- Профиль студента: направление, формат работы, город, навыки из общего справочника. Изменения сохраняются в базе данных.
- Каталог вакансий: поиск по названию и компании, фильтр по направлению, карточки с обязательными и желательными навыками.
- Страница вакансии с подсветкой совпавших и недостающих навыков.
- Персональный подбор по формуле из ТЗ с объяснениями и блоком «What to learn».
- Избранное (сохранение и удаление вакансий).
- Внутренний отклик на вакансию: один активный отклик на вакансию (повторный клик дубликат не создаёт), статусы, отзыв заявки, согласие на передачу данных.
- Демонстрационные вакансии с пометкой Demo.

## Алгоритм подбора

Оценка: `Score = 100 × (0.60·E + 0.15·D + 0.15·A + 0.05·F + 0.05·L)`

| Компонент | Значение |
|---|---|
| E | доля совпавших обязательных навыков |
| D | доля совпавших желательных навыков |
| A | совпадение направления (1 или 0) |
| F | совпадение формата работы (1 или 0) |
| L | совпадение местоположения (1 или 0); удалённая вакансия подходит по местоположению |

Если компонент неприменим (у вакансии нет желательных навыков или студент не указал формат или город), он исключается, а оставшиеся веса нормализуются до суммы 1. Показываются только опубликованные вакансии; при равной оценке выше более новая вакансия. Одинаковые входные данные всегда дают одинаковый результат. Недостающий обязательный навык снижает оценку, но не блокирует отклик.

Контрольный пример: навыки Python, SQL, Excel; направление Data Analytics; формат Hybrid; город Astana. Для вакансии «Data Analyst Intern» (обязательные Python, SQL, Excel, Power BI; желательный Tableau; Astana, Hybrid): E = 0.75, D = 0, A = F = L = 1, итог = 100 × (0.45 + 0 + 0.15 + 0.05 + 0.05) = **70.0**.

Оценка соответствия не является вероятностью найма.

## Технологии

Python, FastAPI, SQLAlchemy, SQLite, Jinja2, Bootstrap 5.

## Запуск

```
git clone https://github.com/aluasarsenova25-coder/AITU-Career-Match.git
cd AITU-Career-Match
pip install -r requirements.txt
python seed.py
python -m uvicorn main:app --reload
```

Сайт откроется по адресу http://127.0.0.1:8000. Команда `python seed.py` создаёт базу данных `career_match.db` и добавляет демо-вакансии (если они уже есть, повторно не добавляет).
Секретный ключ сессий задаётся переменной окружения `SECRET_KEY` (в разработке используется значение по умолчанию, для публичного запуска его нужно заменить).

## Структура проекта

- `main.py` — маршруты и логика веб-приложения
- `database.py` — модели базы данных
- `recommender.py` — расчёт оценки соответствия и блока «What to learn»
- `seed.py` — демонстрационные данные
- `templates/` — HTML-шаблоны

## Не вошло в первую версию

Эти части ТЗ не реализованы из-за ограниченного срока (проект делался за 5 дней одним человеком):

- кабинет работодателя, публикация вакансий и модерация, панель администратора;
- подтверждение email по ссылке и восстановление пароля;
- аналитика рынка труда;
- загрузка резюме и проверка ссылок;
- PostgreSQL, Docker Compose, резервное копирование (вместо них используется SQLite);
- пилотная оценка качества подбора (Precision@5);
- русская и казахская версии интерфейса.

## Ограничения

Демонстрационные вакансии не являются реальными предложениями, отклики на них сохраняются только в демо-базе. Платформа оценивает соответствие указанным требованиям и не гарантирует приглашение или трудоустройство.
